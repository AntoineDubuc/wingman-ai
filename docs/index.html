Yes — any Chromium-based browser works: Chrome, Edge, Vivaldi, and others. The extension uses Chrome's TabCapture API and falls back to web-based OAuth for non-Chrome browsers.
Emotion detection uses Hume AI's research-grade expression measurement API, which analyzes voice prosody (tone, pace, pitch) — not facial expressions. From 48 emotion signals, it distills 4 actionable states: Engaged, Frustrated, Thinking, and Neutral. It's a directional signal, not a lie detector. Think of it as a pulse check on how the conversation is landing.
